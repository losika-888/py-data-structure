# chapter3 元组

## 一、元组的说明

- 元组是一系列不可变的 Python 对象。 元组是序列，就像列表一样。 元组和列表之间的区别是，元组不能像列表和元组使用括号更改，而列表使用方括号。

- 创建一个元组就像放置不同的逗号分隔值一样简单。 您也可以选择将这些以逗号分隔的值放在括号之间。
- 元组的操作特点和字符串、列表保持一致

## 二、元组的创建

```python
#元组的创建
tup1=('physics', 'chemistry', 1997, 2000)
tup2=(1,2,3,4,5,6,7)
tup3="a","b","c","d"
#空元组
tup4=()
#单元素元组
tup5=(1,)
```

## 三、元组的操作

- 元组的索引

```python
#元组的索引
print ("tup1[0]: ", tup1[0])
print ("tup2[1:5]: ", tup2[1:5])
```

```python
list1[0]: physics
list2[0:2]: [1, 2]
```

- 注意：切片索引是不包含右端的元素的

- 元组中的元素不可以被改变，但是可以拼接元组构成一个新的元组，相当于间接改变元组

- 删除元组采用del方法

  ```python
  #删除整个元组
  del tup1
  print(tup1)
  ```

运行后会报错，因为tup1已经不存在了
